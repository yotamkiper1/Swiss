# Save to Swiss (Chrome)

Adds to Chrome's right-click menu:

- **Save to Swiss Recent** on pictures, videos and sounds: saved into Downloads ▸ Swiss, and Swiss puts them in Recent.
- **Add Link / Text / Page to Swiss Recent**: straight into Recent.

Install (once): open `chrome://extensions`, turn on **Developer mode**, click **Load unpacked** and pick this `extras/chrome` folder.
In Swiss, turn on **Downloads** at the top of Recent. The first time you add a link, Chrome asks to open Swiss — tick **Always allow**.
